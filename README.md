# Fall Beans

Браузерная пати-игра в духе Fall Guys для небольшой компании: комнаты до 8 игроков и ботов, у каждой
комнаты свой хост и своё лобби. Играть: **https://киберщит-социум.рф/fallbeans/** — вход свободный.
Нужен Chrome, Edge или Firefox на Windows или Linux; устанавливать ничего не надо.

## Как играть

| Действие | Клавиатура и мышь | Геймпад |
| --- | --- | --- |
| Бег | WASD / стрелки | левый стик |
| Камера | мышь (щелчок по игре захватывает курсор; без захвата — правая кнопка + движение) | правый стик |
| Прыжок | Пробел | A |
| Нырок | E / Shift / левая кнопка мыши | X / B |
| Схватить (держать) | Q / правая кнопка мыши | RB / RT |
| Вырваться из захвата | Пробел несколько раз | A |
| Эмоции (привет, танец, смех, плач, испуг) | 1–5 | крестовина |
| Чат комнаты | Enter — написать и отправить, Esc — закрыть | — |
| Меню (комната, настройки игры, опции) | Esc | — |
| Зритель: другой игрок / обзор | ЛКМ / ПКМ, ← → | — |

**Комнаты.** Игра открывается списком комнат: там же имя и настройки. В открытую комнату входит любой,
в приватную 🔒 — по PIN-коду из 4 цифр (его видит хост в меню комнаты; кого комната уже впускала, тот
возвращается без кода). Каждый может держать одну свою комнату и быть только в одной комнате сразу
(вторая вкладка того же браузера заменяет первую). Создатель комнаты — её хост ⭐, пока он в ней; если
он вышел, хостом становится кто-то из оставшихся, а когда вернётся — роль снова его. Пустая комната
закрывается (после обрыва связи — через 30 секунд). У комнаты есть ссылка (`?room=<код>`, кнопка
«🔗 Ссылка» в меню) и текстовый чат: обычно его не видно, новое сообщение показывает его полупрозрачным.

Хост в меню (Esc) выбирает набор карт (микс, гонки, выживание или свой список) и число раундов (3, 5, 7),
добавляет ботов или ставит галочку «Заполнять свободные места ботами» (боты уступают место приходящим
игрокам) и запускает игру; роль хоста можно отдать другому игроку (кнопка «Отдать хоста» в списке
игроков). Играют все и каждый раунд, раунд длится 1–3 минуты. Перед стартом раунда все стоят на месте,
камера облетает карту.

**Очки.** За раунд — от 10 (первое место) до 0 (последнее), поровну делится между теми, кто занял
места вместе: в гонке по порядку финиша (не добежавшие — по пройденному пути), в выживании по тому,
кто дольше продержался, в «Хвостиках» по очкам. Штрафы: −1 за каждое падение в гонках и «Хвостиках»,
−2 за срезку пути (стоять на бортиках, рамах и т. п.), не больше −4 за раунд; кто 20 секунд ничего
не нажимал — 0 очков за место. Побеждает набравший больше всех (при равенстве — больше побед в раундах,
потом меньше падений). В конце — пьедестал, итоговая таблица и титулы («Самый быстрый», «Задира»,
«Самый неуклюжий»…).

Любую карту можно потренировать с ботами: «Тренировка» в списке комнат и в меню лобби или `/fallbeans/?practice=<id>`.

Карты: гонки «Дверной переполох» (ломающиеся двери, двери по таймеру и ворота с кнопкой: кто-то
держит их открытыми для остальных), «Молоты и качели», «Скользкий склон», «Невидимый мост» (три
стеклянных моста: ложная панель лопается от первого касания, и оттолкнуться от неё нельзя),
«Барабаны», «Гора короны»; выживание «Прыг-клуб», «Перекати-поле» (упал внутрь барабана — бегите
внутри), «Стенобой», «Хекс-а-гон», «Падающие плиты»; очки «Хвостики» (с хвостом бежится медленнее).
Большие карты («Гора короны», «Хекс-а-гон», «Падающие плиты») обычно идут последним раундом.

Гонки собираются из секций (`src/sim/course.ts`): часть испытаний и их порядок, скорости, фазы и
раскладка выбираются по зерну раунда, так что каждый заход немного другой. Между секциями —
площадки-чекпоинты. Кроме препятствий есть батуты, порталы и редкие **бонусы** (пузырь на трассе,
обычно в середине испытаний; на аренах появляется позже): 🍄 великан (больше в 1,8 раза и в 4 раза
тяжелее — его почти не сдвинуть), 🦘 мега-прыжок, ⚡ ускорение; действуют несколько секунд.
Вращающиеся балки («шлагбаумы») сбивают с ног всегда, но проходят над упавшим, а не тащат его.

## Как это устроено

- **Сервер решает всё.** Клиенты шлют только ввод; сервер (Bun) симулирует всех бобов, ботов,
  препятствия, финиши и падения с частотой 120 Гц. Обмануть его, «телепортировавшись» или
  ускорившись, нельзя: ввод проверяется, лишнее отбрасывается.
- **Отзывчивость.** Свой боб предсказывается в браузере той же физикой и сверяется со снимками
  сервера (30 в секунду), с повтором неподтверждённого ввода; остальные плавно интерполируются.
- **Связь.** WebTransport по UDP 443 (датаграммы, без задержек из-за потерянных пакетов);
  если UDP недоступен — автоматически WebSocket через nginx.
- **Карты** описаны один раз (`src/games/<id>/map.ts`) и строятся одинаково на сервере (только
  коллайдеры) и в браузере (с графикой). Движение препятствий — чистая функция времени, поэтому
  синхронизировать его не нужно.
- **Физика** своя, детерминированная: боб — две сферы; бобы толкаются с обменом импульсом, сильный
  удар опрокидывает (упрощённый «рэгдолл» на сервере: боб кувыркается, отскакивает от пола и стен,
  скользит, встаёт), в браузере поверх — кувырки, болтающиеся руки и ноги. С движущихся платформ
  прыгают с их скоростью; нажатия прыжка и нырка, пришедшие на сервер с опозданием, не теряются.
  Захват дотягивается до 2 м (пока кнопка зажата, руки тянутся вперёд) и держит соперника до 3 с;
  лёд скользит, с наклонов сносит. У бобов мимика: радость, смех, испуг, грусть, слёзы, головокружение.
- **Боты** ходят по навигационной сетке статичной части карты (A*: обход стен и толпы, ступеньки,
  прыжки через ямы), а ловушки и движущиеся части проходят по сценарию карты. У каждого бота свой
  характер: меткость, нетерпеливость, любовь к прыжкам и толкотне; они ошибаются, хватают соперников,
  ныряют на финише и перебирают двери, как люди.
- **Графика** (three.js, WebGL 2): пресеты «Среднее / Высокое / Ультра» — сглаживание SMAA 4x
  (SMAA 1x + MSAA 2x + временное 2x: кадры со сдвигом камеры на полпикселя смешиваются с
  предыдущим, перепроецированным по глубине), мягкие тени, освещение от окружения, солнечные лучи
  (рассеяние в воздухе по карте теней и лучи от солнечного диска; отключаются в настройках),
  лёгкая цветокоррекция, GTAO на «Ультра»; имена над бобами — HTML; при просадках FPS качество
  снижается само. Семь уровней детализации M0–M6 (только в браузере: примитивы с меньшим числом
  сегментов, модели упрощаются meshoptimizer при загрузке) с плавным переходом — оба уровня рисуются
  с дополняющими друг друга масками, временное сглаживание превращает их в растворение. У каждого
  материала свой тип поверхности (пластик, мягкие маты, резина, металл, лёд, дерево, стекло, листва,
  трава, камень, ковёр…) — процедурные карты высот, нормалей и шероховатости, наложенные
  трипланарно; полы в полоску, клетку, горошек, ёлочку или волну. Бобы гладкие, без текстуры.
  Небо с плывущими облаками, облака, летающие острова с деревьями и грибами, воздушные шары вокруг
  трассы (не ближе безопасного расстояния), флаги, конусы и звёзды у старта и финиша, птицы,
  пылинки в воздухе.
- **Звуки** — простые синтезированные (Web Audio), музыки нет; шрифт Nunito (OFL).

| Каталог | Что там |
| --- | --- |
| `src/shared` | протокол (JSON-команды, бинарные ввод и снимки), правила раундов, константы |
| `src/sim` | физика с сеткой коллайдеров, мир, конструктор карт, ИИ ботов |
| `src/games` | карты: `meta.ts` (описание) и `map.ts` (постройка, логика, бот) |
| `src/server` | `net/` — HTTP/WebSocket, WebTransport, приём соединений; `rooms/` — список комнат, комната (лобби, игра, чат), очки и титулы, авторитетная арена; билеты и личности игроков (`auth.ts`) |
| `src/client` | браузер: предсказание, интерполяция, рендер, ввод, интерфейс (Preact) |
| `public` | модели (`models/*.glb`, из `blender/fallguys_assets.blend`), шрифты |
| `deploy` | nginx, systemd, установка на сервер |
| `tests` | unit-тесты (Vitest) |
| `src/audit`, `scripts` | аудиты карт и систем; команды: аудит, бенчмарки, трассы, повторы, модели |

## Разработка

Нужен [Bun](https://bun.sh) 1.4+.

```sh
bun install
bun run dev          # сервер + Vite: http://localhost:5173/fallbeans/
bun run dev -- --solo  # разрешить старт игры одному
```

На dev-сервере всегда открыта комната `dev` (`?room=dev`): в неё заходят бенчмарки и браузер агента (Playwright MCP).
Игрок — это токен в `localStorage` браузера, поэтому две вкладки — один игрок; чтобы сыграть с собой,
откройте вторую вкладку с `?profile=b` (только в dev) или в приватном окне.

`dev` создаёт в `.dev/` самоподписанный сертификат (нужен `openssl`, он есть в Git for Windows),
чтобы WebTransport работал и локально (udp/4433). Без него игра идёт по WebSocket.

```sh
bun run check        # типы (TypeScript strict), линтер (Biome), тесты и быстрые аудиты
bun run build        # сборка в dist/
bun run new-game my-map "Моя карта" race   # заготовка новой карты
```

Тесты прогоняют каждую карту ботами на сервере без графики: гонки должны проходиться,
на аренах никто не должен вылетать в первые секунды.

### Аудиты, профилирование, отладка

| Команда | Что делает |
| --- | --- |
| `bun run audit [карта…] [--quick] [--metrics]` | правила карт, точки появления и возрождения, пересечения движущихся частей, навигация, детерминизм, баланс ботов на 5 seed, ощущение управления, ввод и сетевой формат, подсчёт очков |
| `bun run bench [--profile]` | цена тика сервера по картам и по частям (боты, физика…), трафик, память, сравнение с `bench/baseline.json`; `--profile` — самые горячие функции |
| `bun run bench:client` | в браузере (Edge): кадр, CPU по частям кадра, GPU по проходам (сцена, тени, GTAO…) для каждой карты и пресета |
| `bun run stress [--latency 60 --jitter 20 --loss 0.02]` | настоящий сервер и 8 ботов-клиентов на плохой сети: снимки, трафик, задержки, нагрузка |
| `bun run trace <карта> [--stuck]` | пошаговая трасса ботов; `--stuck` сам находит застрявших и показывает, что было перед этим |
| `bun run replay [--i 0]` | точное повторение последних сыгранных раундов dev-сервера (все раунды в dev записываются) |
| `bun run assets [--export [--dry-run]]` | проверка моделей (gltf-validator, бюджеты, нужные коду имена); `--export` — выгрузка из Blender |

В игре (dev-сервер): **F3** — оверлей с кадром, сетью и состоянием боба; **Esc → Dev** — время (пауза,
замедление, шаг), пропуск заставки, конец раунда, телепорты, боты, «сбить», «схватить», профайлер.
Страница сервера: `/fallbeans/debug/` — комнаты, цена тика, ошибки браузеров, журнал, трассы, аудиты.
Ошибки браузеров (`window.onerror`, отказ WebGL, модели, расхождение карты с сервером) приходят на
сервер и видны там и в `journalctl`.

## Выкладка

Сервер: Ubuntu 24.04 (тот же, что у киберщит-социум.рф), доступ `deploy@168.113.157.12`
по ключу `~/.ssh/cybershield_deploy`. Сайт nginx общий и живёт в отдельном репозитории
**SharedServer**; Fall Beans подключается к нему файлами в `/etc/nginx/apps.d/`.

Первый раз:

```sh
cd ../SharedServer && node deploy.mjs     # общий сайт nginx с подключением apps.d
cd ../fallbeans && bun run deploy
```

Дальше — так же `bun run deploy`. Скрипт проверяет код, собирает всё локально, загружает пакет
и запускает `deploy/remote-install.sh`: проверки, Bun в `/opt/fallbeans/bin`, релиз в
`/opt/fallbeans/releases/<время>`, служба `fallbeans` (systemd, отдельный пользователь, сертификат
через `LoadCredential`), nginx, открытие `443/udp` в ufw, проверка здоровья, откат при ошибке
и проверки снаружи.

## Если что-то не так

- `https://киберщит-социум.рф/fallbeans/health` — жив ли сервер игры.
- В углу экрана `UDP` — WebTransport, `TCP` — запасной WebSocket (UDP где-то заблокирован; играть можно).
- Логи: `sudo journalctl -u fallbeans -f` (там же ошибки из браузеров игроков: `client error`).
- Страница отладки в бою: `bun run deploy -- --debug-key <16+ символов>` один раз, затем в браузере
  `https://киберщит-социум.рф/fallbeans/api/debug/login?key=<ключ>` → `/fallbeans/debug/` (только чтение).
- «Версия игры устарела» — страницу нужно обновить после выкладки.
