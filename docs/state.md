# Состояние: с чего продолжать

Открытое состояние: что не проверено, сломано или начато, и с чего продолжать. Не история (она в git): без
хешей, дат и пометок «не закоммичено» — файл должен оставаться верным после коммита. Исправленное — удалять.

Задачи и известные проблемы — в GitHub issues; здесь только то, что начато и не доведено.
