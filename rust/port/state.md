## Проверка без окон

Автор не хочет окон и скриншотов на экране и смотрит интерфейс сам в своей игре (память): правки — сборкой и
`check`, без запусков. Если графику всё же надо проверить снимком — `fb_client --offscreen` (рендер в текстуру
1600×900, без окна и звука; скрипт — `rust/README.md`, «Отладка», «Графика без окна»). Меню без окна не
открывается само (нет курсора) — только через BRP `fb/ui`.

## Не закончено и известные странности

- Особые элементы сцены (плитки, стёкла, порталы) — по-прежнему `StandardMaterial` по `Finish`, без поверхностей
  и узоров; прочее карт — на поверхностях. Створки закрытого портала — диск, растущий из центра.
- Шрифт эмодзи — урезанный Noto Color Emoji (`assets/fonts/emoji.txt` — список); новый эмодзи в тексте без
  перегенерации шрифта рисуется пустым местом (команда — в `decisions.md`).
- Перезапуск на другом API при падении инициализации (план, раздел 7) не сделан: API выбирается флагом или в
  настройках, действует со следующего запуска.
- Окно миграции на Bevy 0.20 закрыто без миграции: Lightyear новее 0.30.1 нет (crates.io, 4 октября).
- Окно не в фокусе на этой машине рисуется на 20 FPS (композитор): кадр мерить с окном на переднем плане.
- В соло-игре раунд кончается, как только единственный человек финишировал или выбыл: зрителя проверять двумя
  клиентами.
- Стресс с ботами в dev-сборке не проходит порог тика (p99 1,1 мс против 1 мс): гонять с `--release`.
- Первый прогон стресса сразу после сборки иногда ловит общее замирание на 0,1–0,6 с — повторить прогон.
- Replay теряет операцию над пешкой, вошедшей между теми же тиками (ошибка TS, `decisions.md`).
- Не разобрано: `jump-club` сид 1 — разница 5,6e-17 в золотом следе.
- Логи и трассы пишутся синхронно из главного цикла.
- Сессия по https через свой прокси со своим CA не проходит: `ureq` проверяет по встроенным корням.
- `cargo xtask deploy` на этой машине не собирает сервер: нет цели `x86_64-unknown-linux-musl`.
- `pkill -f fb_client` убивает и вызывающую оболочку: гасить `pkill -x fb_client` / `pkill -x fb_server`;
  проверять, что `fb_server` не висит на 5887.
