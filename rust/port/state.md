## Начать с

1. **`cargo xtask bench`** — порт `scripts/bench.ts`: мс на тик и p99 по кускам 0,1 с после 3 с разогрева,
   разбивка по секциям (bots, physics, movers, rules, inputs, interact, map — нужна разметка в `Arena::step`),
   время сборки, память комнаты, комнат на ядро; сравнение с `bench/baseline.json` (снят на Windows — для
   сравнения переснять `bun run bench` на этой машине). Размер и кодирование снимка — через `fb_net::wire`,
   поэтому bench живёт в xtask (или отдельном бинарнике в `crates/`), а не в ядре. Harness — `fb_audit::harness`.
   Средний тик и p99 по картам уже сняты разовым тестом (`phases/2.md`, «Стоимость тика»): Rust дешевле TS в
   1,9–4,2 раза; bench должен дать те же числа плюс секции, память и снимок.
2. `cargo xtask trace / replay / new-game` с интерфейсом `bun run …` (`replay` уже есть в `fb_arena::record`,
   нужен CLI; `new-game` — заготовка модуля карты и регистрация в `fb_maps::GAMES`/`MAPS` и `golden!`).
3. CI: кросс-платформенный replay (одни записи → один `state_hash` на Windows и Linux) — последний пункт ворот
   вместе с bench.

- Клиент: события карт, кроме бонуса, по сети не ходят (Фаза 4); сервер играет одну карту из `--map` (комнаты
  и director — Фаза 3).
- Не разобрано: `jump-club` сид 1 — разница 5,6e-17 в золотом следе (на 437 других раундах — 0).
- Replay теряет операцию над пешкой, вошедшей между теми же тиками (ошибка TS, `decisions.md`); проявится, когда
  комната Фазы 3 начнёт записывать раунды.
- `xtask stress` замирает и падает, если диск занят записью (сразу после сборки): процессы пишут логи и трассы
  синхронно из главного цикла (`phases/2.md`). Перед стрессом — `sync`; лучше сделать это в самом `stress` после
  сборки, а трассы писать из отдельного потока.
- Классификатор `stress` записывает в «прочие» откат при первой синхронизации часов клиента (скачок тиков в
  трассе клиента); можно относить его к отдельному столбцу.
- Клиент не рисует `SceneItem::Special` (плитки hex-a-gone, стёкла hidden-bridge, порталы, барабаны…): на
  hex-a-gone не видно пола. Фазы 4/6.
